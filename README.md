## Ini adalah ide proyek saya
> Membuat sistem yang memantau parameter iklim dan cuaca ekstrem secara real time (suhu ekstrem, indeks UV berbahaya, atau curah hujan di atas normal) lewat API cuaca, lalu mengirimkan notifikasi otomatis jika terdeteksi perubahan iklim.
## Bahan-Bahan
- Weather API Key
- Discord Webhook
- Gambar-gambar tanaman
- Artikel-artikel terkait solusi (https://bmkg.com, etc)
- Python Libraries (requests, python-dotenv, schedule)
